README

This program is designed to evaluate no-parity-pochmann algs. It takes a list of algs as input, filters out those that are less finger-friendly, then sorts the remaining algs into categories and outputs that sorted list. 

See my no-parity-pochmann YouTube video, https://youtu.be/Kx_NlSuZaRA.

The program will also filter and sort ANY alg list of any kind.  It works well most of the time.  It just might give occasional strange results, because it will try to divide the algs into different types of no-parity-pochmann alg and then apply slightly different filtering criteria to each, and sometimes that won't make any sense.

Note my notation for whole-cube rotations: The input algs must use capital  X, Y, Z.   My bad!

Note:  I HAVE NOT USED STANDARD SLICE NOTATION.  You can read why here: https://rebrand.ly/greatest-hits-eb84dd.  Instead of E,M,S,  I use H,T,S, like so:  
H = E' 
T = M'
S = S.

To run the program: Select a file from library_of_input_algs. Copy-paste the algs into INPUT_file/INPUT__pythonWidened_finished_algs.txt.  Run the program from main, and then open one of the two newly generated output files.

The library of input algs is the OUTPUT of a companion repo, alg-slice-flip-and-widen, also for my no-parity-pochmann project. 

Output alg lists from this app are intended to be viewed in an Excel spreadsheet I created that has many conditional formatting rules. The spreadsheet was created hand-in-hand with the sorting rules in this Python program. It currently contains 68,000 algs that I've already outputed from filter-and-sort and placed there.  To get faster loading times, I also created a Google Sheets spreadsheet that contains all the algs and their formatting, but no formulas or conditional formatting rules.
The Excel original spreadsheet is here:   https://rebrand.ly/wcoesqe
The Google Sheets mirror spreadsheet is here:    https://rebrand.ly/598dad

To see a color-coded breakdown of YOUR output algs, from any project that you've run through this filter-and-sort:  I suggest you go to the original Excel spreadsheet and download or copy it. Then delete the values from one of my columns and paste your own output from this app in there. The colors and formatting should take effect. 

Any filtering app is subjective. I was guided by these parameters: I was starting with 93 million algs (bad news), but most of them were horrible on the fingers (good news), and I had a great spreadsheet waiting that could aid me in filtering manually using visual cues (good news). I needed to have few enough algs that I could sort them visually, and that number ended up being 68,000 algs.  It wasn't an overwhelming number because they were grouped and color-schemed, etc.  But every project is different, and the sorting criteria I used might be different from what someone else would want. The program is flexible, and you can add your own rules and delete existing rules.

The program begins by eliminating any alg containing B turns, f2 turns, and a few others. It then removes all algs that contain a T (M' in standard slice notation) that isn't part of a pattern like U T U'.  From there, the rules become more obscure, and there are MANY of them. Some can be turned on and off with booleans.

This repo goes hand-in-hand with its partner repo, alg-slice-flip-and-widen. The goal was to generate many algs, then search for the most finger-friendly. This app took the 93 million algs from alg-slice-flip-and-widen and filtered them into just 68,000 algs.
