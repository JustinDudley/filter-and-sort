This program looks at a list of final algs and filters them. For instance, it removes all algs that contain B.


INPUT:  A list of final algs, presumably the output of alg-slice-and-widen
OUTPUT:  A much shorter list with no B, no S2, no T unless surrounded by U, etc.   I will probably also SORT the algs
        as part of this program Presumable those with internal Y and Z will be below those without.
